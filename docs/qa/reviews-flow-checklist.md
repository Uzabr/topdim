# Reviews Flow — Manual QA Checklist

> Дата создания: 2026-04-29

## Предусловия

| Роль | Как создать |
|------|-------------|
| Гость | Открыть сайт без авторизации |
| Покупатель | Зарегистрироваться, купить купон, использовать (partner redeem) |
| Модератор | `UPDATE users SET role = 'MODERATOR'` |
| Администратор | `UPDATE users SET role = 'ADMIN'` |

---

## Публичное чтение отзывов

- [ ] **R-1.** Гость открывает страницу купона → вкладка «Отзывы» → видит approved отзывы
- [ ] **R-2.** Гость не видит PENDING и REJECTED отзывы
- [ ] **R-3.** Гость не видит форму отзыва, видит «Войдите, чтобы оставить отзыв»

---

## Создание отзыва (покупатель)

- [ ] **R-4.** Покупатель с ACTIVE (неиспользованным) купоном → видит «Оставить отзыв можно после использования купона», форма скрыта
- [ ] **R-5.** Покупатель с USED купоном → видит форму с рейтингом и комментарием
- [ ] **R-6.** Покупатель оставляет рейтинг 1-5 и комментарий ≥10 символов → кнопка «Отправить» активна
- [ ] **R-7.** Покупатель нажимает «Отправить» → сообщение «Спасибо за отзыв! Отзыв отправлен на модерацию»
- [ ] **R-8.** После обновления страницы отзыв не появляется на публичной вкладке (статус PENDING)

---

## Дублирование и повторная подача

- [ ] **R-9.** Покупатель с PENDING отзывом пытается отправить ещё один → ошибка «Вы уже оставили отзыв по этому купону»
- [ ] **R-10.** Покупатель с APPROVED отзывом пытается отправить ещё один → ошибка «Вы уже оставили отзыв по этому купону»
- [ ] **R-11.** Покупатель с REJECTED отзывом → может переподать: форма доступна, новый текст сохраняется, статус PENDING

---

## Модерация (admin-app)

- [ ] **R-12.** Модератор/админ заходит в admin-app → Поддержка → Модерация отзывов → видит таблицу PENDING отзывов
- [ ] **R-13.** Модератор нажимает «Одобрить» → отзыв пропадает из списка, появляется на публичной странице купона
- [ ] **R-14.** Модератор нажимает «Отклонить» → модалка с причиной → отзыв пропадает из списка
- [ ] **R-15.** Пустое состояние: если нет PENDING отзывов → «Нет отзывов на модерации 🎉»

---

## Рейтинг и счётчик

- [ ] **R-16.** После одобрения отзыва → средний рейтинг и счётчик отзывов купона обновляются
- [ ] **R-17.** После отклонения → рейтинг и счётчик НЕ меняются

---

## Безопасность

- [ ] **R-18.** `GET /api/v1/reviews/coupon/{id}` — работает без авторизации (гость)
- [ ] **R-19.** `POST /api/v1/reviews` — без JWT → 401
- [ ] **R-20.** `GET /api/v1/reviews/coupon/{id}/eligibility` — без JWT → 401
- [ ] **R-21.** `GET /api/v1/reviews/my` — без JWT → 401
- [ ] **R-22.** `PATCH /api/v1/mod/reviews/{id}/review` — без роли MODERATOR/ADMIN → 403

---

## Регрессионные проверки

- [ ] **R-23.** Каталог купонов не сломан
- [ ] **R-24.** Покупка купона работает
- [ ] **R-25.** Partner redemption (PIN/QR) работает
- [ ] **R-26.** Admin coupon lookup работает

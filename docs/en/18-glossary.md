# 18. Glossary

| Term | Meaning |
|---|---|
| Coupon offer | Public or in-preparation promotion card |
| Coupon option | Price/quantity variant of an offer |
| Purchased coupon | Buyer entitlement instance with PIN/QR |
| Merchant | Partner organization |
| Merchant location | Branch to which staff may be scoped |
| Partner | JWT role for owner or staff-context user |
| Cashier | Staff permitted to redeem; not a distinct JWT role |
| Lead | Initial coupon request |
| Situation | Curated group of coupons |
| Redemption | Consumption of a purchased coupon |
| Sale ledger | Idempotent sale record in coupon-service |
| Security version | Account counter invalidating old JWTs |
| Gateway auth secret | Shared secret protecting forwarded identity headers |
| Database-per-service | Separate logical database owned by each service |
| Demo payment | Completion without a live PSP |
| PSP | External payment service provider |
| EasyPanel | Production Swarm deployment control plane |
| C4 | Context, container, component, and dynamic architecture views |

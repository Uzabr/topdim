# Бренд и терминология sizbiz

## Название

- Публичное название и бренд: **sizbiz**.
- В начале предложения допустимо `sizbiz`; строчное написание является частью
  wordmark.
- Домен: `sizbiz.uz`.
- Не использовать публично: `TopDim`, `Topdim`, `Top Dim`.

## Логотип

Подтверждённый текущим интерфейсом wordmark:

- текст: `sizbiz`;
- текст чёрный;
- фон жёлтый;
- форма фона — скруглённая pill-плашка;
- вокруг логотипа должно оставаться свободное пространство;
- нельзя растягивать, перекрашивать, добавлять тени или менять написание без
  утверждённого бренд-решения.

В репозитории логотип реализован как текстовый UI-компонент, а не отдельный
утверждённый SVG brand master. Для печати и внешних материалов нужен
экспортированный владельцем бренда исходник.

## Внутреннее инженерное имя

`Topdim`/`topdim` — историческое имя проекта в коде и инфраструктуре. Поэтому в
техническом контексте корректно сохранять:

- Java packages `uz.topdim.*`;
- базы `topdim_identity`, `topdim_order` и другие;
- Docker/Swarm/GHCR resources `topdim_*`;
- QR payload `TOPDIM-QR:${qrToken}`;
- существующие пути, классы, тестовые данные и команды.

Эти идентификаторы нельзя переименовывать только ради документации: такое
изменение требует отдельной технической миграции.

## Известное несоответствие реализации

На срез 2026-07-30 отдельные тексты partner/admin-приложений, Telegram-бота,
email/SMS-шаблонов и сообщений backend всё ещё показывают `TopDim`. В рамках
этой задачи код намеренно не изменяется. Для полного публичного ребрендинга
нужна отдельная задача с инвентаризацией строк, переводов, метаданных страниц и
регрессионным тестированием.

## Рекомендуемые формулировки

| Вместо | Использовать |
|---|---|
| «сервис скидок TopDim» | «платформа локальных предложений sizbiz» |
| «наш продавец» | «партнёр» или «мерчант» |
| «акция гарантирует продажи» | «предложение создаёт дополнительный канал привлечения» |
| «скидка без условий» | явно перечислить срок, локацию и ограничения |
| «реальная онлайн-оплата подключена» | «текущий контур оплаты работает в demo-режиме» |

## Термины

| Термин | Простое объяснение |
|---|---|
| Предложение / coupon offer | Условия акции до покупки |
| Купленный купон | Персональное право покупателя воспользоваться предложением |
| Мерчант | Бизнес, исполняющий предложение |
| Партнёр | Пользователь/организация, управляющая мерчантом |
| Погашение | Подтверждение использования купона |
| QR/PIN | Способ найти и проверить купленный купон |
| Lead | Первичная заявка, ещё не опубликованное предложение |
| Модерация | Проверка и подготовка контента/обращения |
| Staff context | Ограничения сотрудника конкретным бизнесом и локацией |

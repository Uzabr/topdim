# 18. Глоссарий

| Термин | Значение |
|---|---|
| Coupon offer | Публичная/готовящаяся карточка акции |
| Coupon option | Ценовой/количественный вариант offer |
| Purchased coupon | Экземпляр права покупателя с PIN/QR |
| Merchant | Партнёрская организация |
| Merchant location | Филиал/точка, к которой может быть привязан staff |
| Partner | JWT-роль владельца или staff-контекст партнёра |
| Cashier | Staff с разрешением redemption, не отдельная JWT-роль |
| Lead | Начальная заявка на coupon |
| Situation | Ручная тематическая подборка купонов |
| Redemption | Погашение purchased coupon |
| Sale ledger | Идемпотентная запись продажи в coupon-service |
| Security version | Версия аккаунта, инвалидирующая старые JWT |
| Gateway auth secret | Shared secret для доверия к forwarded identity headers |
| Database-per-service | Отдельная logical database на сервис |
| Demo payment | Локальное/production-current завершение без реального PSP |
| PSP | Внешний платёжный провайдер |
| EasyPanel | Панель управления production Swarm deployments |
| C4 | Context/container/component/dynamic архитектурные представления |

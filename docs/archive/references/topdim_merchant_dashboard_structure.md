# Структура и функционал мерчант-кабинета TopDim

## 1. Главная идея кабинета мерчанта TopDim

Кабинет мерчанта TopDim должен быть не просто личным кабинетом, а мини-B2B системой для партнера. Владелец видит бизнес, аналитику, финансы и сотрудников. Управляющий управляет филиалом, акциями и операционными процессами. Кассир видит только быстрый экран для погашения купонов.

Основная логика:

```text
TopDim Platform
   ↓
Merchant Company / Бизнес партнера
   ↓
Branches / Филиалы
   ↓
Employees / Сотрудники
   ↓
Cashiers / Кассиры
```

Пример структуры бизнеса:

```text
Кафе "Rayhon"
 ├── Филиал: Чиланзар
 │    ├── Управляющий филиала
 │    ├── Кассир 1
 │    └── Кассир 2
 └── Филиал: Юнусабад
      ├── Управляющий филиала
      └── Кассир 3
```

Главная задача системы:

```text
Продать купон
   ↓
Привести клиента
   ↓
Правильно погасить купон
   ↓
Показать партнеру результат
   ↓
Защитить от фрода, повторного использования и спорных возвратов
```

Важный принцип: если кассир забудет погасить купон, клиент может фактически получить услугу, но в системе купон останется неиспользованным. Это создает риск возврата денег клиенту и убытка для бизнеса. Поэтому экран погашения должен быть максимально быстрым, простым и дисциплинирующим.

---

## 2. Роли в кабинете мерчанта

Для TopDim рекомендуется сделать 5 ролей:

1. Owner / Владелец бизнеса
2. Manager / Управляющий
3. Branch Manager / Управляющий филиала
4. Cashier / Кассир
5. Accountant / Бухгалтер

Для MVP можно начать с трех ролей:

```text
OWNER
MANAGER
CASHIER
```

---

## 3. Owner / Владелец бизнеса

Owner — это главный аккаунт партнера. Он управляет всей компанией, филиалами, сотрудниками, акциями, финансами и настройками.

### Что может Owner

- видеть всю компанию;
- видеть все филиалы;
- видеть все акции;
- видеть продажи;
- видеть выплаты;
- видеть статистику;
- видеть отзывы;
- создавать и удалять сотрудников;
- назначать роли;
- управлять реквизитами;
- смотреть историю погашений;
- видеть эффективность кассиров;
- управлять настройками бизнеса.

### Что не должен делать Owner

Даже владелец не должен иметь доступ к системным операциям платформы:

- менять системные комиссии TopDim;
- вручную менять статус оплаты купона;
- удалять историю операций;
- удалять audit-log;
- изменять уже зафиксированные финансовые события без системного процесса.

---

## 4. Manager / Управляющий

Manager помогает владельцу управлять операционной и маркетинговой частью бизнеса.

### Что может Manager

- создавать черновик акции;
- редактировать описание акции;
- смотреть статистику;
- смотреть продажи;
- смотреть погашения;
- смотреть отзывы;
- добавлять кассиров;
- управлять филиалом;
- смотреть отчеты по своему филиалу или по компании, если Owner дал доступ.

### Что не может Manager

- видеть банковские реквизиты;
- менять юридические данные компании;
- удалять владельца;
- менять комиссию;
- выводить деньги;
- видеть полную финансовую информацию всей компании, если он привязан только к одному филиалу.

---

## 5. Branch Manager / Управляющий филиала

Эта роль нужна, если у бизнеса несколько точек.

### Что может Branch Manager

- видеть только свой филиал;
- видеть купоны, погашенные в его филиале;
- видеть кассиров своего филиала;
- видеть отзывы по своему филиалу;
- смотреть дневную и недельную статистику;
- добавлять или отключать кассиров своего филиала;
- смотреть проблемы: отмены, ошибки погашения, жалобы.

### Что не может Branch Manager

- видеть другие филиалы;
- видеть общую выручку всей компании;
- менять акции на уровне всей компании;
- менять финансовые реквизиты;
- создавать глобальные промо-кампании без подтверждения Owner.

---

## 6. Cashier / Кассир

Cashier — самая ограниченная роль. Его задача — быстро проверить и погасить купон.

### Что должен видеть кассир

- кнопку «Сканировать QR»;
- поле «Ввести PIN/номер купона»;
- результат проверки купона;
- кнопку «Погасить купон»;
- историю своих погашений за смену;
- ошибки по купонам: истек, уже использован, не найден, не относится к этому филиалу.

### Что кассир не должен видеть

- общую выручку;
- комиссию TopDim;
- выплаты;
- аналитику просмотров;
- конверсию;
- отзывы клиентов;
- список всех клиентов;
- настройки бизнеса;
- список всех сотрудников;
- чужие филиалы.

Кассирская зона должна быть минимальной: камера, ручной ввод, быстрый ответ системы, без тяжелых графиков и коммерческой аналитики.

---

## 7. Accountant / Бухгалтер

Эта роль не обязательна для MVP, но полезна для реального бизнеса.

### Что может Accountant

- смотреть выплаты;
- смотреть акты и счета;
- выгружать отчеты;
- видеть финансовые операции;
- видеть сумму к выплате;
- видеть удержанную комиссию;
- видеть возвраты.

### Что не может Accountant

- создавать акции;
- управлять кассирами;
- менять описание бизнеса;
- погашать купоны;
- менять юридические данные без Owner.

# 8. Основные зоны кабинета мерчанта

Для TopDim рекомендуется сделать 4 зоны:

1. Операционная зона кассира
2. Дашборд владельца
3. Управление бизнесом
4. Маркетинг и акции

---

## 9. Зона 1: Операционная зона кассира

Это быстрый экран для точки продаж.

### Основные разделы

```text
1. Сканер QR
2. Ввод PIN
3. Проверка купона
4. Погашение купона
5. История смены
```

### Главный экран кассира

```text
[ Сканировать QR ]

или

[ Ввести PIN-код купона ]

Последние погашения:
- 18:42 — Купон #TD-48291 — Успешно
- 18:37 — Купон #TD-48288 — Ошибка: уже использован
- 18:25 — Купон #TD-48281 — Успешно
```

### Экран после успешной проверки

```text
Купон найден ✅

Акция: -30% на сет
Клиент: Аброр К.
Филиал: Rayhon Чиланзар
Срок действия: до 30.05.2026
Статус: Активен

[ Погасить купон ]
```

### Экран ошибки

```text
Купон недействителен ❌

Причина:
Купон уже использован 25.04.2026 в 19:20

[ Понятно ]
```

## 11. Зона 3: Управление бизнесом

Это административная часть кабинета.

### Основные разделы

```text
1. Профиль компании
2. Филиалы
3. Сотрудники
4. Роли и доступы
5. Реквизиты
6. График работы
7. Фото и описание
8. Категории бизнеса
```

### Профиль компании

Данные компании:

- название бизнеса;
- юридическое название;
- ИНН;
- тип бизнеса;
- город;
- категория;
- описание;
- логотип;
- фотографии;
- контакты;
- Telegram;
- Instagram;
- статус проверки.

### Филиалы

Каждый филиал должен содержать:

- название;
- город;
- адрес;
- геолокацию;
- график работы;
- телефон;
- ответственного менеджера;
- список кассиров;
- активные акции;
- количество погашений;
- рейтинг и отзывы.

## 12. Зона 4: Маркетинг и акции

Это зона для создания, управления и анализа купонов.

### Разделы

```text
1. Все акции
2. Создать акцию
3. Черновики
4. На модерации
5. Активные
6. Завершенные
7. Архив
```

### Создание акции

Партнер заполняет:

- название акции;
- описание;
- условия;
- что входит в купон;
- старая цена;
- новая цена;
- процент скидки;
- количество доступных купонов;
- лимит на одного пользователя;
- срок покупки;
- срок использования;
- филиалы, где можно использовать;
- фото;
- правила возврата;
- ограничения;
- инструкция для кассира.

Важно: партнер может создать акцию, но TopDim должен модерировать ее перед публикацией.

# 15. Какие данные видит каждая роль

## 15.1 Owner видит все

```text
Company:
- название
- юридические данные
- реквизиты
- статус проверки

Branches:
- все филиалы
- адреса
- сотрудники
- график
- продажи по филиалам

Coupons:
- все акции
- продажи
- погашения
- возвраты
- остаток купонов

Finance:
- gross revenue
- commission
- payout amount
- refund amount
- pending payout
- paid payout

Analytics:
- просмотры
- покупки
- конверсия
- redemption rate
- repeat customers
- отзывы
```

## 15.2 Manager видит операционную и маркетинговую часть

```text
Coupons:
- список акций
- статистика акций
- продажи
- погашения
- возвраты без чувствительных финансовых деталей

Branches:
- филиалы
- сотрудники
- кассиры

Analytics:
- просмотры
- покупки
- конверсия
- отзывы
```

Ограничить:

```text
- банковские реквизиты
- полные выплаты
- юридические документы
- смену владельца
```

## 15.3 Branch Manager видит только свой филиал

```text
Branch:
- адрес
- график
- кассиры
- активные акции филиала

Redemptions:
- погашения в филиале
- ошибки погашения
- кто из кассиров погасил

Reviews:
- отзывы по филиалу

Analytics:
- продажи филиала
- погашения филиала
- возвраты филиала
```

Не видит:

```text
- другие филиалы
- общую компанию
- реквизиты
- выплаты всей компании
- глобальную аналитику
```

## 15.4 Cashier видит только рабочий минимум

```text
- название филиала
- свое имя
- активная смена
- QR-сканер
- PIN-ввод
- результат проверки купона
- история своих погашений
```

Кассир не должен видеть полный номер телефона клиента. Можно показывать так:

```text
Клиент: Аброр К.
Телефон: +998 ** *** 45 67
```

Причина: кассиру не нужен полный профиль клиента. Ему нужно только понять, что купон валиден.

## 15.5 Accountant видит финансы

```text
- сумма продаж
- комиссия TopDim
- сумма к выплате
- возвраты
- акты
- счета
- даты выплат
- экспорт в Excel/PDF
```

Не видит:

```text
- QR-сканер
- создание акций
- отзывы
- управление кассирами
```

```text
   ↓

   ↓
```

# 17. Функционал погашения купона

## 17.1 Основной сценарий

```text
Клиент показывает QR или PIN
        ↓
Кассир сканирует / вводит PIN
        ↓
Backend проверяет купон
        ↓
Система показывает результат
        ↓
Кассир нажимает «Погасить»
        ↓
Купон получает статус REDEEMED
        ↓
Фиксируется cashier_id, branch_id, redeemed_at
```

## 17.2 Проверки при погашении

Backend должен проверить:

```text
- купон существует?
- купон оплачен?
- купон активен?
- купон не истек?
- купон не был использован раньше?
- купон относится к этому партнеру?
- купон можно использовать в этом филиале?
- кассир имеет право гасить в этом филиале?
```

## 17.3 Статусы купона

```text
PENDING_PAYMENT
PAID
ACTIVE
REDEEMED
EXPIRED
REFUNDED
CANCELLED
BLOCKED
```

```text

branch_id
cashier_id
action
old_status
new_status
device_id
ip_address
created_at
```

# 22. Короткое ТЗ для разработки

## Цель

Реализовать B2B-кабинет мерчанта для TopDim, где партнеры смогут управлять акциями, филиалами, сотрудниками, погашением купонов, отзывами, выплатами и аналитикой.

## Основные пользователи

- Owner — владелец бизнеса.
- Manager — управляющий.
- Branch Manager — управляющий конкретного филиала.
- Cashier — кассир/администратор точки.
- Accountant — бухгалтер.

## Ключевые модули

1. Авторизация и роли.
2. Управление компанией.
3. Управление филиалами.
4. Управление сотрудниками.
5. Управление купонными акциями.
6. QR/PIN погашение купонов.
7. История погашений.
8. Дашборд и аналитика.
9. Финансы и выплаты.
10. Отзывы и жалобы.
11. Audit-log.

## Главные требования

- Кассир видит только QR/PIN погашение и свою историю смены.
- Owner видит всю компанию, финансы, сотрудников, филиалы и аналитику.
- Branch Manager видит только свой филиал.
- Manager видит операционные и маркетинговые данные, но не банковские реквизиты.
- Все действия по купонам должны логироваться.
- Купон нельзя погасить дважды.
- Купон нельзя погасить в чужом филиале, если акция ограничена филиалами.
- После погашения купон получает статус REDEEMED.
- Все спорные события должны быть проверяемы через audit-log.

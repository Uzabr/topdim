# Documentation Archive

Архив хранит исторические материалы. Эти документы полезны для контекста, но не считаются актуальным источником правды без проверки текущего кода.

## Папки

| Папка | Что хранит |
|---|---|
| `implemented` | уже реализованные планы, backlog, статусы, старые execution notes |
| `ai-prompts` | промпты, которые давались ИИ для реализации отдельных задач |
| `legacy-plans` | старые планы, которые не являются текущей рабочей документацией |
| `references` | reference-документы и идеи для будущего планирования |
| `superpowers/plans` | старые superpowers implementation plans |
| `superpowers/specs` | старые superpowers design specs |

## Правила работы с архивом

- Не начинай новую разработку напрямую по архивному документу.
- Если из архива нужно вернуть идею в работу, сначала создай новый актуальный plan/spec.
- Если документ описывает уже реализованную фичу, сверяй его с кодом и текущими README.
- Не удаляй архивные файлы без отдельного решения: они помогают восстановить историю.

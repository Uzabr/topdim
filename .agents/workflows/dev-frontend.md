## Запуск фронтенда (dev mode)

// turbo-all

1. Перейти в директорию фронтенда и запустить dev server:
```bash
cd /Users/abror/Projects/topdim/frontend/web-app && npm run dev
```

2. Открыть в браузере: http://localhost:5173/

## Сборка production bundle

```bash
cd /Users/abror/Projects/topdim/frontend/web-app && npm run build
```

## Превью production сборки

```bash
cd /Users/abror/Projects/topdim/frontend/web-app && npm run preview
```

# sizbiz

**sizbiz** — платформа купонов и спецпредложений для локального бизнеса Узбекистана
(салоны красоты, барбершопы, спа, фитнес и др.). Клиент покупает купон онлайн,
получает выгоду, а бизнес — новых клиентов и простой инструмент продвижения.

> Проект — участник **President Tech Award**.

## Что в этом репозитории

Это **публичная фронтенд-часть** проекта (веб-приложения на React + TypeScript + Vite):

| Каталог | Приложение |
|---|---|
| `frontend/web-app` | Клиентское веб-приложение (витрина купонов, покупка, профиль, вход через Telegram) |
| `frontend/admin-app` | Админ-панель (модерация, заявки партнёров, купоны) |
| `frontend/partner` | Кабинет партнёра (бизнеса) |

Бэкенд (микросервисы Java/Spring Boot, база, инфраструктура) — **проприетарный и не входит
в этот репозиторий**.

## Технологии (фронтенд)

- React 19 + TypeScript
- Vite
- React Router, TanStack Query, Zustand
- i18n (RU / UZ)

## Локальный запуск

```bash
cd frontend/web-app
npm install
npm run dev
```

Аналогично для `frontend/admin-app` и `frontend/partner`.

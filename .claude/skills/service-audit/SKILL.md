# Service Audit Skill

Use this skill when the user asks to review or audit one microservice.

## Instructions

Ask for or infer the service name.

Analyze:
1. Service purpose
2. Package structure
3. API controllers
4. Service layer
5. Repository/database layer
6. DTOs and validation
7. Transactions
8. Security
9. Tests
10. Configuration
11. Docker/DevOps readiness
12. Production risks

Return the result in Russian.

# Frontend Design

$ARGUMENTS

## Before Coding — Commit to an Aesthetic Direction

- **Purpose**: What problem does this solve? Who uses it?
- **Tone**: Pick one extreme and commit: brutally minimal / maximalist / retro-futuristic / organic / luxury / brutalist / art deco / industrial / editorial. Execute it precisely.
- **Differentiation**: What's the ONE thing someone will remember?
- **Constraints**: Framework, performance, accessibility

**NEVER use generic AI aesthetics:**
- ❌ Overused fonts: Inter, Roboto, Arial, system fonts
- ❌ Cliché colors: purple gradients on white
- ❌ Predictable layouts, cookie-cutter patterns

## Implementation Checklist

**Typography**
- Pair a distinctive display font with a refined body font
- Unexpected, characterful choices that elevate the UI

**Color & Theme**
- CSS variables for consistency
- Dominant color + sharp accents > timid distributed palette
- Commit — don't hedge

**Motion**
- One well-orchestrated page load > scattered micro-interactions
- Staggered reveals (`animation-delay`), scroll triggers, hover surprises
- CSS-only preferred; Motion library for React

**Spatial Composition**
- Asymmetry, overlap, diagonal flow, grid-breaking elements
- Generous negative space OR controlled density — pick one

**Atmosphere**
- Gradient meshes, noise textures, geometric patterns, layered transparencies
- Dramatic shadows, decorative borders, grain overlays

## Quality Bar
Maximalist needs extensive animations. Minimalist needs precision in spacing and typography. Both are valid — the key is intentional execution.

Match implementation complexity to the aesthetic vision.
